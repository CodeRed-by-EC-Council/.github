## Free CTF Challenges
Try a real capture-the-flag challenge, about 1 hour each:
- [Zsoft](https://coderedpro.com/products/zsoft-10d?utm_source=github&utm_medium=org_readme&utm_campaign=github_org) (beginner) - Perform network scanning and web enumeration to identify a SQL Injection vulnerability.
- [Hidden](https://coderedpro.com/products/hidden-10d?utm_source=github&utm_medium=org_readme&utm_campaign=github_org) (beginner) - Performing SMB enumeration, identifying hidden data via Alternate Data Streams (ADS), extracting credentials.
- [Superman](https://coderedpro.com/products/superman-10d?utm_source=github&utm_medium=org_readme&utm_campaign=github_org) (beginner) - Network scanning, web application credential guessing, gaining initial SSH access with compromised credentials.
- [Library](https://coderedpro.com/products/library-10d?utm_source=github&utm_medium=org_readme&utm_campaign=github_org) (intermediate) - Combining multiple offensive security techniques to compromise a Windows system.
- [Ghost Render](https://coderedpro.com/products/ghost-render-10d?utm_source=github&utm_medium=org_readme&utm_campaign=github_org) (intermediate) - Scanning and enumerating a web app to find a SQL injection in a login form.
- [Poisoned Gate](https://coderedpro.com/products/poisoned-gate-10d?utm_source=github&utm_medium=org_readme&utm_campaign=github_org) (advanced) - Poison AI models to bypass automated access controls.
- [Chain Intel](https://coderedpro.com/products/chain-intel-10d?utm_source=github&utm_medium=org_readme&utm_campaign=github_org) (advanced) - AI supply chain reconnaissance using OSINT and human-centric intelligence.
